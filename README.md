# Marlow's Crystal Optimizer (Horizon Native Mod)

A 1:1 recreation of the famous Java **Marlow's Crystal Optimizer** for Horizon by **CayMac**:

- **0ms Instant Break Prediction:** Client-side entity prediction immediately removes attacked End Crystals without waiting for the server's remove packet, giving you a 0ms ping feel during CPvP combos.
- **Zero Miss Penalty:** Removes artificial attack miss penalties when striking crystals so clicks are never swallowed.
- **Fast Place (Obsidian & Crystal):** Removes the artificial 4-tick right-click delay when holding End Crystals or Obsidian for ultra-smooth crystal placement.
- **Auto-Break on Hold:** Break crystals appearing under your crosshair while holding down attack.
- **100% Server-Legal:** Sends only standard vanilla attack packets. Does not use macros, reach hacks, or automated clicking.

## Configuration

Open **Options > Mods > Marlow's Crystal Optimizer** to customize:
- `Predict Break (0ms)`: ON / OFF
- `Auto-Break (Hold)`: ON / OFF
- `Fast Place (Obsidian/Crystal)`: ON / OFF
- Toggle Keybind in Controls.
